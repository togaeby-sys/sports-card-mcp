# Bundled display fonts

These fonts are unmodified official Google Fonts distributions under the SIL Open Font License 1.1. Each directory contains its corresponding `OFL.txt`.

- `black-han-sans/BlackHanSans-Regular.ttf`: Korean impact headlines
- `do-hyeon/DoHyeon-Regular.ttf`: Korean supporting copy and labels
- `anton/Anton-Regular.ttf`: condensed Latin words and numerals

Sources:

- https://github.com/google/fonts/tree/main/ofl/blackhansans
- https://github.com/google/fonts/tree/main/ofl/dohyeon
- https://github.com/google/fonts/tree/main/ofl/anton

Do not remove the license files when redistributing the font software.
