# ADR-001: 역할 기반 영화 포스터 시리즈 파이프라인

**Status:** Accepted
**Date:** 2026-09-02
**Deciders:** 프로젝트 사용자, Sports Card MCP 구현자

## Context

기존 MCP는 AI 영화 포스터 판과 로컬 SVG 편집 모드를 모두 제공했지만, AI 한글을 보정할 때 거대한 평면 SVG 패널을 덮을 수 있었다. 또한 단일 `player_image` 중심 구조여서 훅·상황·반전·절정·CTA에 필요한 사진 수와 구도를 시리즈 전체 관점에서 판단하지 못했다. 결과 파일의 크기와 포맷만 맞으면 시각 품질이나 타이포 검수와 무관하게 완료로 취급되는 문제도 있었다.

## Decision

`create_reels_series`를 고임팩트 릴스 제작의 기본 경로로 추가한다.

1. 시리즈 디렉터가 카드 역할별 레이아웃과 선수 사진 0~2장을 결정한다.
2. 생성형 모델은 사람이 없는 완성형 영화 포스터 판을 만든다.
3. 선수는 세그멘테이션 알파만 원본 RGB에 적용하고 알파 바운딩 박스를 정규화한 뒤 Sharp로 합성한다.
4. 영화 포스터 모드에서 대형 로컬 SVG 제목을 금지한다.
5. 기술 품질과 AI 타이포 검수를 별도 게이트로 취급한다.
6. AI 타이포를 확인하기 전 상태는 `review_required`이며 `passed`가 아니다.
7. manifest와 `retry_cards`로 실패하거나 반려된 카드만 다시 생성한다.
8. 모든 카드의 밀도와 서사 흐름을 한 번에 확인할 수 있는 검수용 contact sheet를 만든다.

## Options Considered

### Option A: AI 완성 포스터 판 + 검수 후 원본 선수 합성

| Dimension | Assessment |
|---|---|
| 시각 임팩트 | 높음 |
| 한글 결정성 | 검수 필요 |
| 구현 복잡도 | 중간 |
| 원본 선수 보존 | 높음 |

**Pros:** 승인된 영화 포스터 레퍼런스의 깊이, 재질, 조명과 프레임 구성을 유지한다.

**Cons:** AI 한글 오탈자를 자동으로 완전히 배제할 수 없어 검수 단계가 필요하다.

### Option B: 모든 타이포그래피를 로컬 SVG로 렌더링

| Dimension | Assessment |
|---|---|
| 시각 임팩트 | 낮음~중간 |
| 한글 결정성 | 높음 |
| 구현 복잡도 | 낮음 |
| 원본 선수 보존 | 높음 |

**Pros:** 철자와 수치가 정확하다.

**Cons:** 현재 SVG 엔진으로는 승인된 블록버스터형 3D 타이포그래피를 재현하지 못한다.

### Option C: AI 판 위에 대형 로컬 보정 패널 덮기

| Dimension | Assessment |
|---|---|
| 시각 임팩트 | 낮음 |
| 한글 결정성 | 높음 |
| 구현 복잡도 | 낮음 |
| 구도 일체감 | 매우 낮음 |

**Pros:** 특정 글자만 빠르게 교체할 수 있다.

**Cons:** 영화 포스터의 깊이와 레이아웃을 파괴하고 프레젠테이션형 결과를 만든다.

## Trade-off Analysis

사용자의 최우선 기준은 첫 장에서 스크롤을 멈추게 하는 영화 포스터형 임팩트다. 따라서 Option A를 채택하고 정확성 문제는 완료 상태를 분리하는 방식으로 해결한다. Option B는 정보 밀도가 높은 편집형 카드에만 유지하며 Option C는 시리즈 경로에서 금지한다.

## Consequences

- 훅·상황·반전·절정·CTA가 같은 템플릿을 반복하지 않는다.
- 사진이 없는 카드와 여러 선수가 필요한 카드 모두 표현할 수 있다.
- AI 카피는 검수 전까지 게시 가능한 완성본으로 취급되지 않는다.
- 고품질 자동 OCR 또는 영역 편집 공급자는 추후 교체 가능한 검수 계층으로 추가할 수 있다.
