# Sports Card MCP 제작 계약

## 책임 분리

Project003는 편집장과 오케스트레이터다.

Project003가 담당한다:

- 매일 제작할 주제와 사실관계 확정
- 스토리와 릴스 구분
- 카드 수, 순서, 서사 역할 결정
- 선수 사진 검색 및 절대경로 제공
- 계정 성과 분석과 디자인 학습
- 음악, 전환 효과, MP4 결합
- 캡션, 해시태그, 예약 및 게시
- 게시 후 성과 수집

Sports Card MCP는 카드 제작만 담당한다.

MCP가 담당한다:

- 전달받은 명세에 따른 카드 디자인
- 선수 원본 누끼와 픽셀 보존 합성
- AI 배경 또는 영화 포스터 판 제작
- 정확한 로컬 한글 렌더링
- 카드별 1080×1920 PNG 출력
- 타이포, 구도, 선수 배치 품질 검수
- 전체 contact sheet 생성
- 실패하거나 반려된 카드만 재생성

## 제작 모드

### 스토리

- Project003 분류: `content_type: story`
- MCP 호출: `create_sports_card`
- 로컬 정확 타이포그래피를 기본으로 사용한다.
- AI는 선수 없는 배경에만 사용한다.
- 점수, 선수명, 기록, 날짜는 AI 이미지 안에 생성하지 않는다.
- 빠른 제작과 정확성을 우선한다.

### 릴스

- Project003 분류: `content_type: reels`
- MCP 호출: `create_reels_series`
- `render_provider`: `chatgpt_ui` (기본값)
- MCP가 Chrome의 ChatGPT 웹에서 선수 없는 영화 포스터 판을 자동 제작·저장한다.
- 선수 사진은 GPT 앱으로 다시 그리지 않는다.
- MCP가 원본 선수 누끼를 Sharp로 합성한다.
- 훅, 상황, 반전, 절정, CTA의 역할을 그대로 따른다.
- ChatGPT 시각 검수와 기술 검수를 통과한 뒤 전체 contact sheet와 전달 JSON을 자동 생성한다.
- GPT 앱을 사용할 수 없으면 임의로 낮은 품질 모드로 전환하지 않는다.
- 대체 생성이 필요하면 Project003가 명시적으로 `render_provider: fal_api`를 지정한다.

## Project003가 MCP에 전달할 필수 정보

- `series_id`
- `render_provider`(릴스, 생략 시 `chatgpt_ui`)
- `output_dir`
- 주제와 사실 요약
- 시즌, 리그, 구단명과 구단색
- 카드별 `id`, `role`, 정확한 카피
- 선수 사용 여부와 사진 절대경로
- 배경 프롬프트
- 계정 분석에서 얻은 규칙을 반영한 확정 카드 문구·역할·구도 입력
- 필요한 경우 seed와 스타일 레퍼런스

MCP는 주제, 게시 일정, 음악, 캡션을 임의로 결정하지 않는다.

## 품질 불변 조건

- 최종 카드는 1080×1920 PNG다.
- 선수 얼굴, 유니폼, 등번호, 헬멧, 배트와 로고는 원본 픽셀을 유지한다.
- 생성형 AI에 선수 원본을 넣어 다시 그리지 않는다.
- 영화 포스터의 대형 제목을 평면 SVG 패널로 덮지 않는다.
- 파워포인트형 레이아웃을 허용하지 않는다.
- AI 한글은 검수 전까지 `passed`로 처리하지 않는다.
- 문제 있는 카드만 재생성한다.
- 단순히 파일이 존재한다는 이유로 완료 처리하지 않는다.

## MCP 결과 사용

Project003는 MCP가 반환한 다음 결과만 사용한다.

- 카드별 PNG 절대경로
- 카드별 품질 상태
- 전체 contact sheet
- 검수 필요 카드 목록
- 실패 카드와 실패 단계
- API 호출 수와 캐시 사용 정보

카드가 `review_required`이면 영상 결합이나 게시 단계로 진행하지 않는다.
